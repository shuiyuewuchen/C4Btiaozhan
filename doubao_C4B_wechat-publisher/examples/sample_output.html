为什么需要这个工具

写公众号文章最痛苦的不是写内容，而是排版。

字号要多大？边距要多少？代码块怎么显示才好看？引用框怎么加颜色？这些问题每篇文章都要重新纠结一遍。

💡 好的排版应该是"自动"的——你只管写内容，样式交给工具。

WeChat Publisher Pro 就是来解决这个问题的。

核心功能

1. 五套主题一键切换

不同风格的文章配不同的主题：

  • 商务蓝：适合产品发布、行业分析
  • 暖橙风：适合成长随笔、生活记录
  • 森系绿：适合读书分享、自然科普
  • 极简黑白：适合设计感强的文章
  • 默认灰调：通用百搭

python convert_to_wechat.py article.md output.html --theme blue

2. Callout 高亮框

文章里需要强调的内容，用高亮框比加粗更有视觉冲击力。

📘 这是一个普通提示框，适合补充说明知识点。

⚠️ 这是一个警告框，适合提醒读者注意的坑。

3. 自动目录

长文阅读最大的痛点是读者迷路。超过 3 个标题时，工具会自动生成目录。

使用三步走

  1. 写：用 Markdown 写文章，可以加 frontmatter 和 callout
  2. 转：运行一条命令，生成公众号 HTML
  3. 贴：浏览器打开，全选复制，粘贴到公众号编辑器

💬 写作的本质是表达，不是排版。把排版交给工具，把时间留给思考。

支持的格式

输入格式 说明
Markdown (.md) 完整支持表格、代码块、callout
Word (.docx) 提取标题和段落，保留粗体斜体
HTML (.html) 直接清洗并应用公众号样式

小技巧

  • 标题加 --- frontmatter 可以自动渲染文章头部
  • 用 --toc 参数开启目录
  • 用 --footer 自定义版权信息
  • 中文和英文混排时，工具会自动加空格
